Catppuccin Mocha
================

Catppuccin Mocha is a dark theme with mauve Fluent icons, muted connection tree
guides, taller connection rows, and compact Config text.

To enable it, open :menuselection:`File --> Options --> Theme`, select
**Catppuccin Mocha**, click **OK**, and restart mRemoteNG.

To switch back, select a different theme in the same menu and restart.
